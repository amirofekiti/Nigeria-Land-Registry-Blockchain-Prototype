# Nigeria Land Registry Blockchain Prototype

Research prototype supporting the manuscript **Design and Evaluation of a Blockchain-Assisted Land Administration Framework for Secure and Auditable Property Registration in Nigeria**.

This project treats blockchain as an **audit, provenance and workflow-integrity layer**, not as a substitute for the statutory land registry. It does not treat an NFT or wallet address as legal land title.

Development is proceeding through reviewable phases. The first implementation branch adds the contract model, automated tests, architecture documentation and CI before any testnet deployment or manuscript performance claims.
